How to run

1

Clone the repo — git clone https://github.com/Roopchand415/facemaskdetection

2

Install dependencies — pip install tensorflow opencv-python matplotlib pillow

3

Run the script — python facemaskdetection.py — a webcam window will open.

4

Press Q to quit — closes the webcam window cleanly.
